\section{Method}
\label{sec:method}

\subsection{Overall Framework}
\label{sec:framework}

Given a surveillance frame, the proposed pipeline performs face detection and alignment via an off-the-shelf detector, then extracts a 512-d embedding with our lightweight \emph{Surveillance-Attention EdgeFace} (SA-EdgeFace). The embedding is compared by cosine similarity for verification. The student backbone is a ShuffleNetV2 enhanced with the proposed Surveillance Attention Block (SAB, Sec.~\ref{sec:sab}), trained with a combination of ArcFace supervision, large-teacher knowledge distillation (Sec.~\ref{sec:distill}), and surveillance-degradation augmentation (Sec.~\ref{sec:aug}).

\subsection{Surveillance Attention Block (SAB)}
\label{sec:sab}

Surveillance faces are typically low-resolution and lose global structural cues; recognition therefore relies more on local detail texture. We propose the SAB, which augments a feature tensor with three lightweight branches: channel attention, spatial attention, and multi-scale local detail enhancement.

\textbf{Channel attention.} We adopt an ECA-style module without FC reduction. Let $\mathbf{x}\in\mathbb{R}^{C\times H\times W}$. Global average pooling yields $\mathbf{g}\in\mathbb{R}^{C}$, and a 1D convolution of kernel $k$ produces the channel weight
\begin{equation}
    \mathbf{c} = \sigma\!\left(\mathrm{Conv1D}_k(\mathbf{g})\right),
    \label{eq:channel}
\end{equation}
where $\sigma$ is the sigmoid. This branch adds only $k$ parameters.

\textbf{Spatial attention.} A depth-wise $5{\times}5$ convolution followed by a $1{\times}1$ projection produces a spatial weight map
\begin{equation}
    \mathbf{s} = \sigma\!\left(\mathrm{PWConv}(\mathrm{DWConv}_{5\times5}(\mathbf{x}))\right).
    \label{eq:spatial}
\end{equation}

\textbf{Local detail enhancement.} To explicitly reinforce local texture at multiple scales,
\begin{equation}
    \mathbf{d} = \mathrm{BN}\!\left(\mathrm{PWConv}\!\left(\mathrm{DW}_{3\times3}(\mathbf{x}) + \mathrm{DW}_{5\times5}(\mathbf{x})\right)\right),
    \label{eq:detail}
\end{equation}
where $\mathrm{DW}$ denotes depth-wise convolution. The SAB output combines the three branches with a learnable scalar $\alpha$:
\begin{equation}
    \mathrm{SAB}(\mathbf{x}) = \mathbf{x} \odot \mathbf{c} \odot \mathbf{s} \;+\; \alpha \cdot \mathbf{d}.
    \label{eq:sab}
\end{equation}
Each branch can be independently toggled for ablation (Sec.~\ref{sec:ablation}).

\subsection{Backbone Integration}
\label{sec:backbone}

We use ShuffleNetV2 as the lightweight backbone. To keep the parameter overhead small, a single SAB is inserted at the end of each of the two deepest stages (stage~3 and stage~4), rather than after every unit. With a $1.0{\times}$ width multiplier this raises the parameter count from $1.78\,$M to $2.09\,$M ($+17.7\%$); with $0.5{\times}$, from $0.87\,$M to $0.93\,$M ($+7.4\%$).

\subsection{Surveillance Degradation Augmentation}
\label{sec:aug}

To improve robustness to surveillance artifacts, each aligned face is randomly degraded with a composition of: (i) down-up resampling to a target size drawn from $[40, 0.8H]$; (ii) Gaussian blur with kernel $\in\{3,5,7\}$; (iii) random rectangular occlusion covering up to $15\%$ area; (iv) JPEG recompression at quality $[20,60]$; (v) brightness/contrast jitter. Four severity levels (\emph{none/light/medium/heavy}) control the per-operation probabilities.

\subsection{Knowledge Distillation}
\label{sec:distill}

A heavy teacher (InsightFace buffalo\_s, MobileFaceNet backbone) provides 512-d embeddings. To avoid running the teacher online, teacher features are precomputed once per training sample and cached. The total training objective is
\begin{equation}
    \mathcal{L} = w_{\mathrm{arc}}\,\mathcal{L}_{\mathrm{arc}} + w_{\mathrm{feat}}\,\mathcal{L}_{\mathrm{feat}} + w_{\mathrm{rel}}\,\mathcal{L}_{\mathrm{rel}},
    \label{eq:total}
\end{equation}
where $\mathcal{L}_{\mathrm{arc}}$ is the ArcFace margin loss on the student logits,
\begin{equation}
    \mathcal{L}_{\mathrm{feat}} = 1 - \frac{\langle \hat{\mathbf{z}}_s,\, \hat{\mathbf{z}}_t\rangle}{\|\hat{\mathbf{z}}_s\|\,\|\hat{\mathbf{z}}_t\|}
    \label{eq:feat}
\end{equation}
is the cosine feature distillation between normalized student embedding $\hat{\mathbf{z}}_s$ and cached teacher embedding $\hat{\mathbf{z}}_t$. We additionally explored a relation distillation term $\mathcal{L}_{\mathrm{rel}}{=}\|\mathbf{R}(\mathbf{z}_s){-}\mathbf{R}(\mathbf{z}_t)\|_F^2$ that preserves the pairwise similarity matrix within each mini-batch, but found it unhelpful on small training sets (Sec.~\ref{sec:distill_analysis}). The default weights are $w_{\mathrm{arc}}{=}1.0$, $w_{\mathrm{feat}}{=}0.1$, $w_{\mathrm{rel}}{=}0$. Setting $w_{\mathrm{feat}}{=}0$ recovers the ArcFace-only baseline for ablation.
